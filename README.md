
# WAZA+ PRO - APK REAL con compilación automática

### Cómo tener tu APK en 3 minutos SIN instalar nada:

1. Crea un repo nuevo en github.com (ponle waza-pro)
2. Sube TODO este ZIP a ese repo
3. Ve a pestaña ACTIONS
4. Dale a "Compilar WAZA+ PRO APK" > Run workflow
5. Espera 2 min y descarga tu APK en Artifacts > WAZA-PRO-APK

Listo, APK real firmada para instalar en cualquier Android.
